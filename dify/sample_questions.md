# Dify 演示样例问题

下面的问题适合在 Dify Chatbot / Chatflow 调试、GitHub 展示或面试演示时使用。

## 项目概览类

1. 这个项目主要解决什么问题？
2. 这个项目为什么适合数据分析或产品运营实习岗位展示？
3. 这个项目的数据来源是什么，样本规模有多大？

## 数据清洗类

4. 这个项目做了哪些数据清洗步骤？
5. 为什么清洗后从 100,000 行变成了 99,956 行？
6. 为什么要把时间戳转换成 Asia/Shanghai 业务时间？

## 指标口径类

7. 为什么用户级浏览-购买转化率比较高？
8. 用户级转化率和用户-商品级顺序转化率有什么区别？
9. 用户-商品级顺序浏览-购买转化率为什么更适合解释商品路径？
10. 这个项目里的复购率是怎么理解的？

## 业务洞察类

11. 加购未购买用户有什么运营价值？
12. 复购用户可以怎么做留存运营？
13. 品类 `2735466` 的购买次数排名第一，这能说明什么？
14. 购买高峰小时是 13:00，运营上可以怎么使用这个结论？

## SQL / Python 技术类

15. 这个项目用 Python 和 Pandas 做了哪些工作？
16. SQL 分析里用了哪些常见方法，比如 CTE、CASE WHEN、GROUP BY 或窗口函数？

## 看板展示类

17. Excel 看板主要展示了哪些指标和图表？
18. 面试展示看板时，应该先讲哪几个模块？

## 面试表达类

19. 这个项目适合怎么写进简历？
20. 面试时我应该怎么用 1 分钟介绍这个项目？这个项目还有哪些不足和后续优化方向？
