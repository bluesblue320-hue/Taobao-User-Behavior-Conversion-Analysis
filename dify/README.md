# 淘宝用户行为分析 AI 问答助手

## 功能定位

淘宝用户行为分析 AI 问答助手是一个基于 Dify Knowledge / Chatflow 构建的个人作品集扩展功能，用于回答关于本项目的项目背景、数据来源、清洗流程、指标口径、分析结论、业务洞察、看板设计和简历表达等问题。

这个功能不是重新做数据分析，也不替代 Python、SQL、Excel 看板或报告本身。它的作用是把项目中已经完成的数据分析报告、README、SQL 说明和展示材料整理成可问答的 AI 入口，让 HR、面试官或同学可以用自然语言快速了解项目内容。

## 适合展示的能力

- 将已有数据分析项目进一步产品化为 AI 问答入口。
- 演示“数据分析 + AI 应用落地”的作品集扩展思路。
- 让面试官快速追问项目背景、指标口径、业务解释和简历表达。
- 体现对 AI 产品测试场景中知识库边界、回答可信度和引用来源的理解。

## 使用边界

- 本目录只提供 Dify 配置说明、知识库文件建议、系统提示词和样例问题。
- 不包含 Dify App ID、API Key、线上 Web App 链接或真实 API 调用代码。
- 不应把该功能描述成企业真实生产系统，只能表述为个人作品集扩展功能。
- 回答必须基于本项目已有文档和公开样本分析结果，不应编造不存在的数据、图表或业务背景。
